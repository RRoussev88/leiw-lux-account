# leiwlux.com (GitHub Pages)

Static site generated by `build.mjs` (plain Node, no dependencies). The generated HTML is committed, so GitHub Pages serves the repo root as-is.

## Edit copy
All text lives in `src/strings/{fr,en,de,lb}.json`. Same keys in every file (the build fails if they differ).
`lb` needs a native-speaker check.

## Build and test locally
    node build.mjs
    python3 -m http.server 8080      # then open http://localhost:8080/

## Layout
- `src/` sources: `config.json`, `strings/`, `layout.html`, `pages/*.html`
- `assets/` css, js, fonts (self-hosted Cinzel), images, vendored supabase-js (pinned)
- Generated: `index.html`, `404.html`, `sitemap.xml`, `robots.txt`, `fr/ en/ de/ lb/`, `password/`

Never commit secrets. Only the public Supabase URL and anon key appear here.
